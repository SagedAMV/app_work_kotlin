# 🌌 مجرة (Galaxy) — نظام إدارة مواقع الاتصالات

تطبيق Android شخصي (مستخدم واحد) لإدارة دورة حياة مواقع الاتصالات بالكامل:
المواقع، المعدات، الاحتياج، الشبكات (المجرة)، الصيانة، والتقارير.

> نُفّذ هذا المشروع وفق ملف [`تعليمات.md`](تعليمات.md) وبعد تطبيق منهجية
> [`تفكير.md`](تفكير.md) بشكل صارم. الملفان يُمنع حذفهما من المستودع.

---

## 🧱 الالتزامات المعمارية

| الالتزام | التنفيذ |
|---|---|
| Kotlin + Jetpack Compose | ✅ Material 3، State Hoisting، LazyColumn |
| Clean Architecture + MVVM | ✅ طبقات `data` / `domain` / `presentation` / `di` |
| أوفلاين 100% | ✅ لا يوجد إذن `INTERNET` إطلاقًا في Manifest |
| قاعدة بيانات محلية | ✅ Room + TypeConverters + Foreign Keys (CASCADE) |
| عربية فقط + RTL | ✅ كل النصوص عربية، الاتجاه مفروض على مستوى النظام |
| وضع ليلي أساسي | ✅ أسود عميق + أزرق سماوي + أخضر نيون |
| حقن الاعتماديات | ✅ Hilt (KSP) |
| أقل إصدار | ✅ Android 11 (API 30) |

## 🗂️ هيكل المشروع

```

├── data/
│   ├── local/                  # Entities (15) + DAOs (14) + Converters + Database
│   ├── repository/             # تطبيقات المستودعات + تفضيلات المستخدم
│   └── seed/DemoDataSeeder.kt  # 50 موقعًا تجريبيًا ببذرة ثابتة
├── domain/
│   ├── model/Enums.kt          # كل التعدادات بعناوين عربية
│   ├── repository/             # واجهات المستودعات (الطبقة النظيفة)
│   └── usecase/                # قواعد العمل: الحذف الآمن، الصرف، الإغلاق، التنبيهات

├── security/Security.kt        # BiometricPrompt + النسخ الاحتياطي + المسح الآمن

└── ui/
    ├── theme/                  # الهوية البصرية الداكنة
    ├── navigation/             # 7 شاشات رئيسية + المسارات الثانوية
```

## 🧮 قواعد العمل المنفذة

1. منع حذف موقع يحتوي معدات أو روابط نشطة (رسالة سبب مفصلة).
2. إغلاق التذكرة يسجل `resolutionTimeMinutes` تلقائيًا.
3. صرف الاحتياج يخصم المخزون + يسجل في `AuditLog` (لا خصم جزئي أبدًا).
4. وصول المخزون للحد الأدنى ينشئ تنبيهًا تلقائيًا.
5. تنبيه الصيانة قبل 7 أيام من الاستحقاق.
6. تنبيه انتهاء عمر المعدة (تاريخ التركيب + العمر الافتراضي).
7. كل إضافة/تعديل/حذف تُسجل في سجل التدقيق.
8. المجرة تعرض الحالة اللحظية للروابط والمواقع.
9. لا يوجد أي اتصال شبكي.

## 🌠 محرك المجرة

- عرض Nodes & Edges على Canvas مع أنيميشن نبض ضوئي على الروابط النشطة.
- الروابط المعطلة ترسم بالأحمر المتقطع الوامض.
- ألوان حسب الحالة، سماكة حسب الأولوية، فلترة حسب النوع والتصنيف والحالة.
- وضع 3D مبسط: دوران قرص الشبكة بإسقاط منظوري (بدون مكتبات ثقيلة).
- النقر على عقدة يفتح بطاقة الموقع، والنقر على رابط يعرض تفاصيله.
- حاسبة كاملة: موازنة الرابط + منطقة فرينل + خط النظر مع انحناء الأرض (k = 4/3).

## 🏗️ البناء والتشغيل

```bash
# يتطلب Android Studio / Gradle 8.5 و JDK 17
gradle wrapper          # أول مرة فقط لتوليد الغلاف
./gradlew assembleDebug
./gradlew test          # اختبارات الوحدة لحالات الاستخدام والحسابات
```
