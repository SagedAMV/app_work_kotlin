# مجرة — تطبيق إدارة المواقع الشخصية

تطبيق Android بسيط وعملي لإدارة المواقع، مكتوب بـ Kotlin و Jetpack Compose،
ويعمل **أوفلاين 100٪** (لا يوجد إذن إنترنت إطلاقًا).

> الإصدار الحالي: **2.0.0** — النسخة المبسطة حسب `تعليمات.md`.

## ما الذي يفعله التطبيق؟

- ✅ **إدارة المواقع فقط**: إضافة موقع بالاسم، تعديل، حذف، وبحث.
- ✅ **تفاصيل اختيارية لكل موقع**: المواد الموجودة، الاحتياج، ما يحتاج
  صيانة، وما تم سحبه — نصوص حرة يضيفها المستخدم إن شاء.
- ✅ **سجل صيانة لكل موقع**: تاريخ + ملاحظات + من نفّذها (اختياري).
- ✅ **تنبيه بسيط**: إشعار نظام واحد عند قرب موعد الصيانة المجدول
  (خلال 7 أيام أو عند التجاوز)، يُفحص عند فتح التطبيق فقط — بلا عمال
  خلفية ولا جدولة دورية.
- ✅ **مرفقات لكل موقع**: صور تُعرض كمعرض + ملفات، مع حذف.
- ✅ **نسخة احتياطية موثوقة**: تصدير/استيراد ملف قاعدة البيانات عبر
  منتقي الملفات الآمن (SAF)، مع التحقق من سلامة الملف قبل الاستبدال.
- ✅ **قفل بسيط**: رمز سري من 4 إلى 8 أرقام عند فتح التطبيق
  (يُخزَّن كبصمة لا نصًا صريحًا).
- ✅ **وضع ليلي/نهاري**.

## ما الذي حُذف في النسخة 2.0؟

| النظام الملغى | السبب |
|---|---|
| نظام GPS والإحداثيات | لا حاجة لتتبع جغرافي |
| نظام المخزون (Inventory) | خارج نطاق إدارة المواقع |
| الحسابات الراديوية (`RadioMath`) وحاسبة الروابط | غير مطلوبة |
| نظام التنبيهات المعقد (WorkManager + عامل دوري) | استُبدل بفحص بسيط عند الفتح |
| نظام الأذونات المعقد (`UriPermissionVault`) وأذونات الموقع | أُذونات مرفقات مضمّنة ومبسطة |
| سجل التدقيق (Audit) وسجل الموقع التاريخي | لا تتبع للتغييرات |
| نظام التقارير والتصدير (Reports/Exporters) | لا تقارير |
| المعدات، الروابط، التذاكر، أوامر الشغل، الاحتياج/BOQ | خارج النطاق المبسط |

## بنية قاعدة البيانات (5 جداول فقط)

| الجدول | المحتوى |
|---|---|
| `sites` | id, name, notes, createdDate, lastModified |
| `site_details` | siteId, availableMaterials, neededMaterials, maintenanceMaterials, withdrawnMaterials, nextMaintenanceDue |
| `maintenance_logs` | siteId, maintenanceDate, notes, performedBy |
| `attachments` | siteId, filePath, fileType (IMAGE/PDF), uploadedDate |
| `app_settings` | settingKey, settingValue |

الترحيل من الإصدار السابق (2 → 3) غير مدمّر: يحافظ على أسماء المواقع
وملاحظاتها ومرفقاتها، ويسقط الجداول الملغاة (انظر `GalaxyMigrations.kt`).

## البنية التقنية

```
data/local       ← كيانات Room وواجهات DAO وقاعدة البيانات والترحيلات
data/repository  ← تطبيقات المستودعات (تفويض إلى DAO)
domain           ← واجهات المستودعات + حالات الاستخدام المبسطة
di               ← وحدات Hilt
notify           ← إشعار بسيط واحد (قناة صيانة وحيدة)
security         ← النسخ الاحتياطي والمسح وإعادة التشغيل
ui               ← ثلاث شاشات: المواقع، التفاصيل، الإعدادات + قفل بسيط
```

- **الحد الأدنى**: Android 11 (API 30) — الهدف API 34.
- **الاعتماديات**: Compose (Material 3)، Navigation، Hilt، Room، Coil.
- بلا WorkManager، بلا مكتبة بصمة، بلا أي مكتبة تتطلب شبكة.

## البناء والاختبار

```bash
./gradlew build    # بناء debug و release
./gradlew test     # اختبارات الوحدة (محقق مدخلات الموقع)
```

## ملاحظات

- `تعليمات.md` و`تفكير.md` ملفا عمل مرجعيان — **لا يُحذفان** من المستودع.
- `الاسئلة-والاقتراحات.html` ملف جلسة العمل: اقتراحات على شكل أسئلة
  (لكل سؤال 3 خيارات + خيار كتابة جواب حر)، وفيه زر تصدير الأجوبة إلى
  ملف `الاسئله.md` مرتب ليُرفع إلى المستودع وتُنفَّذ الاقتراحات المجابة.
  يعمل أوفلاين بلا أي اعتماديات، وهو خارج كود تطبيق Kotlin.
- التطبيق شخصي وليس للنشر العام.
